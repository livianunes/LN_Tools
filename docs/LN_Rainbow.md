# LN_Rainbow

> Generates a rainbow ramp, or maps an existing image through the hue wheel.

Two behaviours in one node, chosen automatically:

- **Nothing connected** — generates a rainbow ramp.
- **Something connected** — applies the rainbow to the connected input, by converting to
  HSV, driving hue from the image, and converting back.

Handy for UI elements, prisms, spectral fringing and quick reference gradients.
